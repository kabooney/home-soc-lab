# 🛡️ Home SOC Lab

## Overview

This project documents my Home Security Operations Center (SOC) built in VirtualBox for hands-on cybersecurity training.

---

## Lab Environment

### Host Machine

- Windows 11 Pro

### Hypervisor

- Oracle VirtualBox

### Virtual Machines

- Windows 11 (Target)
- Kali Linux (Attacker)
- Ubuntu Server (SIEM)

# Home SOC Lab

## Objective

Build a home Security Operations Center (SOC) using virtual machines to practice cybersecurity skills including:

- Network monitoring
- Malware analysis
- Log analysis
- Threat detection
- Incident response


## Lab Environment

Host Machine

- Windows 11 Pro

Virtualization

- VirtualBox

Virtual Machines

- Windows 11
- Kali Linux
- Ubuntu Server


## Phase 1 - Environment Setup

Completed:

- Installed VirtualBox
- Created Windows 11 VM
- Created Kali Linux VM
- Created Ubuntu Server VM
- Verified all VMs boot successfully
